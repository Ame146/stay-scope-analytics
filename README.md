Complete Lovable Prompt

Build a premium Airbnb Market Intelligence web application called StayScope AI with a luxury dark theme inspired by modern fintech dashboards. Use Space Grotesk for headings, Inter for body text, and IBM Plex Mono for KPI numbers. The color palette should use Deep Midnight (#0B1020) backgrounds, glassmorphism cards (#131B2E) with subtle borders, Mint Green (#6EE7B7) for positive metrics, Royal Purple (#8B5CF6) for charts, Warm Gold (#FFB703) for highlights, and Coral Red (#EF4444) for alerts. Create a left sidebar navigation with Lucide icons, a top search bar, notification area, and profile avatar. The dashboard should feature animated KPI cards with sparklines, a large interactive map showing neighborhood performance, trend charts, host rankings, seasonal analytics, customer reviews, occupancy, pricing, revenue estimates, and availability. Add AI-generated insights, neighborhood comparison, export to PDF/CSV, responsive design, dark/light mode, Framer Motion animations, hover effects, rounded 22px cards, soft shadows, blurred glass effects, and a polished, premium user experience that feels like an enterprise real estate analytics platform rather than a standard dashboard.

This aesthetic is distinctive enough to look like a commercial SaaS product while remaining clean and highly readable—exactly the kind of portfolio piece that attracts attention from recruiters and hiring managers.
